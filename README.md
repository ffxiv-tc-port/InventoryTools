# Allagan Tools（InventoryTools）

[Allagan Tools](https://github.com/Critical-Impact/InventoryTools) 的台服移植版，追蹤角色/僱員/公會倉庫的所有道具，並提供製作規劃、市場整合與各式資料查詢視窗。

## 功能

- **道具追蹤**：統整所有角色、僱員、公會倉庫（含跨伺服器/跨帳號）內的道具數量與位置
- **篩選系統**：自訂複雜搜尋條件建立道具清單，可在背包中即時高亮顯示符合條件的道具
- **製作規劃**：`/crafts` 開啟製作清單視窗，自動計算所需材料並可整合背包/倉庫庫存；`/craftoverlay` 開啟製作用小型疊加視窗
- **市場公告板整合**：於道具視窗內查詢市場價格
- **道具詳細視窗**：`/moreinfo`（別名 `/itemwindow`）顯示道具的商人、取得來源等資訊
- **裝備建議**：`/atrecommend`（別名 `/atr`）依角色職業/等級推薦可裝備的更好裝備
- **資料查詢視窗**：`/duties`（任務）、`/mobs`（怪物）、`/atnpcs`（NPC）、`/airships`（飛空艇）、`/submarines`（潛水艇）、`/retainerventures`（僱員探險）
- **提示視窗整合**：滑鼠懸停道具即可查看其收納位置
- **主要指令**：`/allagantools`（別名 `/atools`，開啟道具清單視窗）、`/openlist <清單名稱>`（開關單一清單視窗）、`/athighlight`（別名 `/atf`，切換清單高亮）、`/atclearhighlights`、`/atcloselists`、`/atclearall`、`/atconfig`（設定視窗）、`/athelp`（說明視窗）
